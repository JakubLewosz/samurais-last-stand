# Samurai's Last Stand

Fork i rozwijany projekt gry 2D w Godot 4.

Repozytorium pokazuje podstawy pracy z silnikiem Godot: scenami, skryptami GDScript, sterowaniem postacią, przeciwnikami, pociskami, falami walki i eksportem gry.

![Main menu](./screens/MainMenu.png)

## Najważniejsze Elementy

- projekt Godot 4.3,
- sterowanie postacią w grze 2D,
- przeciwnicy i proste zachowania w grze,
- pociski, ataki i system obrażeń,
- fale przeciwników oraz walka w arenie,
- kilka scen gry, ekran menu i ekran końca gry,
- eksport gry dla Windows.

## Technologie

- Godot 4
- GDScript
- sceny 2D
- eksport Windows

## Uruchomienie

### W Godot

1. Zainstaluj Godot 4.3 lub zgodną wersję Godot 4.
2. Otwórz plik `project.godot`.
3. Uruchom projekt z poziomu edytora.

### Eksport Windows

Repozytorium zawiera wyeksportowane pliki:

- `Samurai's Last Stand.exe`
- `Samurai's Last Stand.pck`

## Sterowanie

- `A` / `D` - ruch w lewo i prawo
- `Space` - skok
- `Shift` - dash
- Lewy przycisk myszy - atak
- Prawy przycisk myszy - strzał

## Status Projektu

Projekt traktuję jako część portfolio GameDev i praktykę pracy z Godotem. Kod i struktura projektu mogą zawierać elementy eksperymentalne, ponieważ repozytorium powstało jako rozwijany fork gry.
